🌐 Host di GitHub Pages (Gratis)
Langkah 1 — Buka github.com → daftar akun gratis
Langkah 2 — Klik + → New repository → beri nama nazareth-app → Public → Create
Langkah 3 → Klik Add file → Upload files → upload file nazareth-app.html
Langkah 4 → Settings → Pages → Source: main branch → Save
Langkah 5 → URL app akan menjadi: https://[username].github.io/nazareth-app/nazareth-app.html
✅ Setelah di GitHub Pages, mikrofon akan langsung berfungsi karena URL sudah HTTPS.
Alternatif lebih cepat — Netlify Drop:
Buka netlify.com/drop → seret file nazareth-app.html ke halaman → dapat URL HTTPS dalam 30 detik.
